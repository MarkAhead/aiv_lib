## AIv-lib – Shared Utilities & Services for Social-Media-Bot

> **Status:** Actively maintained  
> **Location:** `aiv_lib/` (repo root)  
> **License:** Inherits the root repository licence

---

### 1. What is AIv-lib?

`AIv-lib` is a **batteries-included toolkit** that powers every Cloud Run Job and CLI script in the *Social-Media-Bot* mono-repo.  
Instead of re-implementing plumbing code in each job, we keep **all cross-cutting concerns** here:

* Database access (Firestore & relational)
* GCP / AWS storage helpers
* AI integrations (OpenAI, Google Vertex, ElevenLabs, Stable-Diffusion …)
* Video / image / audio processing utilities
* Structured logging, secret management & background-job helpers

> When you create a new job with `build_run/cloud_run_job_init.sh`, the Dockerfile automatically copies **AIv-lib** into the image and installs it in *editable* mode.

---

### 2. Installation / Update

**Inside a job Dockerfile** (already generated by the template):
```dockerfile
COPY ../../aiv_lib /opt/aiv_lib
RUN pip install -e /opt/aiv_lib
```

**Local development** (top-level repo):
```bash
pip install -e ./aiv_lib  # editable install for auto-reload
```

### 3. Quick-start Example

```python
from aiv_lib.logger import setup_logging
from aiv_lib.cloud_gcp_storage import GCSHelper

logger = setup_logging()

gcs = GCSHelper()
local_path = gcs.download("gs://my_bucket/input.mp4")
# … do stuff …
_ = gcs.upload(local_path, bucket="processed")
```

### 4. Detailed Module Guide

Below is a **curated inventory** of the most frequently used files.  
*(Stars ★ mark the modules you'll likely touch in everyday job code.)*

#### 4.1 Top-level Utilities

| Path | Responsibility |
|------|---------------|
| `ai/` | Experimental AI agents and prompt builders *(WIP)* |
| `aws_polly_util.py` | Thin wrapper around AWS Polly TTS |
| `aws_s3_util.py` | Legacy S3 helpers (kept for back-compat) |
| `cloud_gcp_functions.py` | Invoke Google Cloud Functions |
| `cloud_gcp_storage.py` ★ | Read/write to GCS buckets |
| `file_util.py` ★ | Temp dirs, safe writes, glob helpers |
| `util.py` | Misc one-liners |

#### 4.2 AWS Sub-package (`aws/`)

| Path | Responsibility |
|------|---------------|
| `aws/__init__.py` | Package marker |
| `aws/aws_s3_util.py` ★ | Canonical S3 helper used by other modules |

#### 4.3 Database Layer (`db/`)

| File | Purpose |
|------|---------|
| `db/common.py` | Base Firestore & SQL helpers |
| `db/db_account_metadata.py` | CRUD for account settings |
| `db/db_caption_store.py` ★ | Captions & subtitles collection access |
| `db/db_existing_artifacts.py` | Metadata for already-generated media |
| `db/db_initialize.py` | One-shot migrations & seeds |
| `db/db_mappings.py` | ID mapping tables |
| `db/db_Music_store.py` | Music & track metadata |
| `db/db_publishing_workflow.py` | Orchestration state for publish workflow |
| `db/db_ready_artifacts.py` ★ | Queue of artifacts ready to post |
| `db/db_standalone.py` | Light DB helpers for ad-hoc scripts |
| `db/db_video_post_store.py` | Metrics for published video posts |
| `db/model.py` | Pydantic models shared by DB layer |

#### 4.4 Logging

| Path | Responsibility |
|------|---------------|
| `logger/setup_logging.py` ★ | Opinionated `logging` config loader |
| `logger/logging_config.yaml` | Default log schema |

#### 4.5 Media & AI Helpers

| File | Purpose |
|------|---------|

| `util_caption_writer.py` | Render styled SRT / VTT files |

|------|---------|
